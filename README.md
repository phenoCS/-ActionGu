# 任务修仙计时器

极简桌面自律工具（Python + Tkinter，纯本地单机，无联网、无登录、无云同步）。
以「任务闭环」作为修行标准，单个任务专注累计 ≥5 分钟计入有效修行，集齐 3 个有效任务晋升一阶。
境界体系严格采用《蛊真人》蛊师体系，一转起步，九转巅峰为凡世尽头。

## 一、如何运行

### 1. 安装 Python
确保本机已安装 Python 3.8 及以上版本（Windows 推荐从 python.org 下载安装，安装时勾选 “Add Python to PATH”）。

### 2. 准备依赖
本程序仅使用 Python 标准库（tkinter 随 Python 自带），无需额外安装第三方库。
如系统缺失 tkinter（极少数精简版 Python），可执行：
```
pip install tk
```

### 3. 启动程序
将 `main.py` 与 `data.json`（首次运行会自动生成）放在同一目录，双击 `main.py`，
或在命令行中进入该目录执行：
```
python main.py
```

程序关闭时会自动把「任务清单、当前境界、本轮积攒任务数量、历史总任务数」写入 `data.json`，
下次打开自动加载。

## 二、基本用法

1. 在左侧输入框填写任务（如「学习线性代数」），点【新增任务】或回车添加。
2. 点击某条任务将其选中（背景变蓝），此时【开始任务】可用。
3. 点【开始任务】启动计时，界面实时显示 时:分:秒。
4. 需要中断时点【暂停】/【继续】；想放弃本次计时点【结束计时】（不计入积累）。
5. 单次专注累计 ≥5 分钟时点【完成任务】：
   - 不足 5 分钟：弹窗提示「修行尚浅，还需要更多沉淀，不计入修行积累。」可继续积累；
   - 达到 5 分钟：计入 1 个有效任务。集齐 3 个有效任务即晋升下一阶，并弹窗「些许风霜些许愁，无足之鸟不回头！」。
6. 任务可保留在列表，也可随时点【删除】移除（修行中的任务需先结束计时）。

## 三、如何打包为 Windows exe 文件

### 1. 安装打包工具 PyInstaller
```
pip install pyinstaller
```

### 2. 执行打包命令
进入 `main.py` 所在目录，运行：
```
pyinstaller -F -w -i NONE main.py
```
参数说明：
- `-F`：打包成单个 exe 文件；
- `-w`：以窗口程序运行（不弹黑框）；
- 如需自定义图标，可用 `-i your_icon.ico` 替换 `-i NONE`。

### 3. 获取成品
打包完成后，在当前目录的 `dist/` 文件夹中会生成 `main.exe`。
直接双击即可运行，数据与 `data.json` 保存在 `main.exe` 同级目录（即脚本目录）。
如需分发，把 `dist/main.exe` 单独发给他人即可（无需安装 Python）。

> 提示：若希望 `data.json` 与 exe 始终同目录，程序已使用脚本/可执行文件所在目录作为存储路径，无需额外配置。

## 四、一键式安装包（免安装，双击即可运行）

适合分发给任意 Windows 电脑：**对方无需安装 Python、无需任何操作**，只要双击即可使用。
（Python 检测 + 自动安装逻辑改编自 v11 项目的 FlashTap 安装脚本。）

打包目录需包含以下文件（整体复制即可）：

```
任务修仙计时器/
├─ 启动.bat          ← 用户双击这个（入口）
├─ launcher.ps1      ← 自动检测/安装 Python 并启动程序
├─ main.py           ← 主程序
└─ data.json         ← 首次运行自动生成（可先不放入）
```

使用方式：

1. 把整个文件夹复制到目标电脑任意位置（U 盘、桌面均可）。
2. **双击 `启动.bat`**：
   - 若本机已有 Python 3.10+ → 直接启动；
   - 若没有 → 自动从镜像下载并静默安装（当前用户，免管理员、无弹窗），装完自动启动。
3. 数据 `data.json` 自动保存在该文件夹内，随文件夹一起迁移。

离线场景：若目标电脑无网络，可先把 `python-3.12.7-amd64.exe` 放到该文件夹内，
启动器会优先使用本地安装包，完全不联网。

> 说明：本方式依赖系统自带 PowerShell（Windows 7 SP1+ 均具备）。如需彻底不依赖任何环境，
> 仍可用上文「三、打包为 exe」生成完全独立的 `main.exe`。

## 五、测试模式说明

`main.py` 顶部有两个开关，便于开发/验证：

```python
TEST_MODE = True     # 测试模式开关
TEST_SECONDS = 3     # 测试模式下，单个任务只需专注 3 秒即计为有效
```

- 设为 `True`：有效任务门槛降到几秒、且取消「不足 5 分钟」弹窗（改为状态栏提示），
  可秒级验证晋升流程，适合快速自测。
- **正式发布 / 日常使用请改回 `TEST_MODE = False`**，恢复 5 分钟门槛与原有提示文案。
