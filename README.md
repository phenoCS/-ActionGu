# 任务修仙计时器

极简桌面自律工具（Python + Tkinter，纯本地单机，无联网、无登录、无云同步）。
以「任务闭环」作为修行标准，单个任务专注累计 ≥5 分钟计入有效修行，集齐 3 个有效任务晋升一阶。
境界体系严格采用《蛊真人》蛊师体系，一转起步，九转巅峰为凡世尽头。

---

## 一、运行方式（统一渠道：双击 启动.bat）

本程序**统一通过 `启动.bat` 双击运行**，无需手动装 Python。

### 分发包里包含这些文件（整体复制即可）

```
任务修仙计时器/
├─ 启动.bat          ← 用户双击这个（入口，会自动请求管理员权限）
├─ launcher.ps1      ← 自动检测/安装 Python 并启动 main.py
├─ main.py           ← 主程序
├─ data.json         ← 首次运行自动生成（记录任务/境界/进度）
└─ (可选) python-3.12.7-amd64.exe  ← 放到同目录可离线安装 Python
```

### 使用步骤

1. 把整个文件夹复制到目标电脑任意位置（U 盘、桌面均可）。
2. **双击 `启动.bat`**：
   - 若本机已有 Python 3.10+ → 直接启动，无需任何额外操作；
   - 若没有 → 会弹出 **UAC 提权窗口（点"是"）**，自动下载并静默安装 Python（全用户安装，方式与 v11 安装器一致，360 等安全软件下也能正常安装），装完自动启动。
3. 数据 `data.json` 自动保存在该文件夹内，随文件夹一起迁移。

> 说明：首次安装 Python 需要管理员授权（UAC 弹窗），这是 360 / 系统策略下能成功安装 Python 的必要条件，与 v11 安装器行为一致。装过一次之后，后续双击都不再需要安装。

## 二、为什么用"启动器"这条路，而不是打包成 exe

早期曾提供过 PyInstaller 单文件 `任务修仙计时器.exe`，但最终统一为启动器方案，原因是：

- **更轻量**：启动器只是几个 KB 的脚本；exe 把 Python 解释器整体打包，体积约 11MB。
- **启动更快**：exe 每次启动都要把约 11MB 解压到临时目录再运行；启动器直接用系统 Python 跑源码，秒起。
- **更易维护**：改功能只改 `main.py` 即可；exe 改完必须重新打包。
- **稳定性相同**：启动器已改为"提权 + 全用户安装"，与 v11 完全一致，360 环境下也能正常安装 Python，不再有 1625 问题。

**唯一 exe 仍占优的场景**：目标机器完全无法获得管理员权限、装不了 Python。若遇到这种极端情况，可改用 `dist/任务修仙计时器.exe`（免安装单文件，双击即跑，但体积大、启动慢）。这属于备选，不在统一渠道内。

## 三、基本用法

1. 在左侧输入框填写任务（如「学习线性代数」），点【新增任务】或回车添加。
2. 点击某条任务将其选中（背景变蓝），此时【开始任务】可用。
3. 点【开始任务】启动计时，界面实时显示 时:分:秒。
4. 需要中断时点【暂停】/【继续】；想放弃本次计时点【结束计时】（不计入积累）。
5. 单次专注累计 ≥5 分钟时点【完成任务】：
   - 不足 5 分钟：状态栏提示「修行尚浅，还需要更多沉淀，不计入修行积累。」可继续积累；
   - 达到 5 分钟：计入 1 个有效任务。集齐 3 个有效任务即晋升下一阶，并弹窗「些许风霜些许愁，无足之鸟不回头！」。
6. 任务可保留在列表，也可随时点【删除】移除（修行中的任务需先结束计时）。

## 四、排错（闪退 / 运行无反应）

1. **启动方式**：`启动.bat` 会自动请求管理员权限（UAC 弹窗，点"是"），并以
   `InstallAllUsers=1`（全用户）方式静默安装 Python——与 v11 安装器做法一致，360 下可正常安装。
2. **红字 "依然找不到 python" + 退出码 1625**：
   这是 **360 等安全软件拦截了非提权 Python 的 MSI 安装**。若仍看到此错，说明 UAC 授权没成功
   （请右键 `启动.bat` →「以管理员身份运行」再试一次）。
   极端无管理员环境可用备选 exe：`dist/任务修仙计时器.exe`。
3. **窗口一闪而过**：`启动.bat` 结束前已加 `pause`，任何错误都会停在屏幕上，请把窗口文字发回。
4. **SmartScreen 拦截**：从 GitHub 下载的压缩包解压后首次运行可能被拦截，点「更多信息 → 仍要运行」即可。
5. **无网络无法自动装 Python**：把 `python-3.12.7-amd64.exe` 放到同目录，启动器优先用本地包离线安装。
6. **编码红线**：`launcher.ps1` 与 `启动.bat` 为纯英文，不要往里加中文，否则中文 Windows 会误报语法错误。

## 五、测试模式说明

`main.py` 顶部有两个开关，便于开发/验证：

```python
TEST_MODE = True     # 测试模式开关
TEST_SECONDS = 3     # 测试模式下，单个任务只需专注 3 秒即计为有效
```

- 设为 `True`：有效任务门槛降到几秒、且取消「不足 5 分钟」弹窗（改为状态栏提示），可秒级验证晋升流程。
- **正式发布 / 日常使用请改回 `TEST_MODE = False`**，恢复 5 分钟门槛与原有提示文案。

## 六、备选：打包为单文件 exe（仅极端无管理员环境用）

若目标电脑完全无法安装 Python，可把程序打成单文件 exe（需在有 Python 的机器上构建）：

```bash
pip install pyinstaller
pyinstaller -F -w --name 任务修仙计时器 main.py
```

成品在 `dist/任务修仙计时器.exe`，双击即运行（内置 Python，无需安装）。
注意：`main.py` 已做路径适配，打包后 `data.json` 会保存在 exe 同级目录。
